# saraGongora_Ag14_DSI_REC

## Descrição

Este projeto apresenta os principais atrativos turísticos da cidade de Votorantim-SP por meio de uma página web desenvolvida com HTML5 e o framework W3.CSS.

## Tecnologias Utilizadas

* HTML5
* W3.CSS

## Funcionalidades

* Exibição de atrativos turísticos de Votorantim;
* Uso de cartões (cards) com imagens e descrições;
* Layout responsivo;
* Interface simples e organizada.



## Responsividade

O layout se adapta automaticamente a diferentes tamanhos de tela utilizando os recursos do framework W3.CSS.

## Referências

As imagens foram obtidas em fontes públicas, como:

* Google Imagens;
* Sites de turismo;
* Prefeitura de Votorantim.
